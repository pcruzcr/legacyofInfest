## 2. API Contract Compliance

| Contract (from `22_API_CONTRACTS.md` §2.3) | Implementation | Status |
|---|---|---|
| `EventBus` — Singleton-style static class. All methods are classmethods. | All public methods decorated with `@classmethod`; class-level `_subscribers` and `_queue` shared across all callers | ✅ |
| `subscribe(event_name: str, callback: Callable[..., None]) -> None` | Implemented exactly — appends callback to `_subscribers[event_name]` list, creating the list if absent | ✅ |
| `unsubscribe(event_name: str, callback: Callable[..., None]) -> None` | Implemented exactly — removes callback from list; no-op if not found | ✅ |
| `emit(event_name: str, **data: Any) -> None` — "Queues the event; dispatched at the start of the next frame" | Implemented exactly — appends `(event_name, data)` tuple to `_queue`; no immediate dispatch | ✅ |
| `dispatch() -> None` — "Called once per frame by App, before scene update. Drains the queue." | Implemented exactly — swaps queue with empty list, iterates, invokes each subscriber's callback with `**data` | ✅ |
