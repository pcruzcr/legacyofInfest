## 1. Root Cause

`main.py` did not call `App.run()`. The file contained only:

```python
_app = App()  # noqa: F841
```

Without `.run()`, the application constructed the engine subsystems, created the window momentarily, printed a message, and exited immediately. The main loop (event processing, clock tick, scene update/draw, display flip) never executed.

**Why it happened:** The original Phase 1 placeholder comment explicitly stated "does NOT call App.run() during Phase 1 — that will be wired in Phase 3 once the scene system is complete." The wiring was either missed or reverted after Phase 3 was marked complete.
