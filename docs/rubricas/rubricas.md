# Rubrics — Academic Grading Instruments

**Course:** Legacy of InFest
**Reference:** `docs/27_ACADEMIC_RUBRICS.md` (full version)

## Grade Weighting

| Instrument | Weight |
|------------|--------|
| Quizzes | **15%** |
| Lab practices | **20%** |
| Evaluación Práctica I | **15%** |
| Evaluación Práctica II | **15%** |
| Evaluación Práctica III | **15%** |
| Proyecto Integrador Invenio Fest | **20%** |
| **Total** | **100%** |

## Final Grade Formula

```
Final = (Quices_avg × 0.15)
      + (Labs_avg × 0.20)
      + (Eval_Practica_I × 0.15)
      + (Eval_Practica_II × 0.15)
      + (Eval_Practica_III × 0.15)
      + (Invenio_Fest × 0.20)
```

## Quiz Rubric (15%)

| Criterion | Points |
|-----------|--------|
| Conceptual accuracy | 40 |
| Applied reasoning | 30 |
| Mathematical correctness | 20 |
| Clarity of expression | 10 |
| **Total** | **100** |

## Lab Practice Rubric (20%)

| Criterion | Points |
|-----------|--------|
| Functional correctness | 35 |
| Correct use of framework API | 25 |
| Code quality | 20 |
| In-lab demonstration | 20 |
| **Total** | **100** |

## Practical Evaluation Rubrics

See `docs/eval_practica/eval_practica.md` for detailed rubrics for each of the three practical evaluations, or `docs/27_ACADEMIC_RUBRICS.md` SS4–SS6 for the complete version.

## Proyecto Integrador Invenio Fest Rubric (20%)

| Criterion | Points |
|-----------|--------|
| Effective application of visual techniques | 25 |
| GUI/interface quality | 20 |
| Appropriate use of visual resources | 15 |
| Integration of graphics components | 20 |
| Individual contribution clarity | 10 |
| Presentation and final demonstration | 10 |
| **Total** | **100** |

## Grading Consistency Rules

1. **Calibration session** required before Class 5
2. **Code-quality criteria** checked with shared checklist
3. **Disagreements >15 points** resolved by professor mediation
4. **Pass threshold** for each practical: ≥60/100
5. **Remediation** required for any practical below threshold (except Eval III)
