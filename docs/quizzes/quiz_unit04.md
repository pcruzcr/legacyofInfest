# Quiz — Unit IV: Interpolation & Animation

**Course:** Legacy of InFest  
**Duration:** 15 minutes  
**Total:** 10 points  

---

## Questions

### 1. Linear Interpolation (2 pts)
Given A = 10 and B = 30, what is lerp(A, B, 0.25)? Show your work.

### 2. Easing Functions (2 pts)
Describe the visual difference between `ease_in_quad` and `ease_out_quad`. When would you use each?

### 3. Keyframe Animation (2 pts)
A sprite moves from x=0 to x=200 over 2 seconds using linear interpolation. What is its position at t=0.5s and t=1.5s?

### 4. Bézier Curves (2 pts)
A quadratic Bézier curve has control points P0=(0,0), P1=(50,100), P2=(100,0). Compute the point at t=0.5 using the Bernstein basis.

### 5. Spline vs Linear (1 pt)
Why would you use a Catmull-Rom spline instead of linear interpolation for a camera path?

### 6. Time Scaling (1 pt)
If deltaTime doubles, what happens to a lerp-based animation? How can you fix it?
